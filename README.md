# Averon | Creative Studio Portfolio

A modern, high-performance, interactive digital studio portfolio featuring dynamic cursor effects, interactive particle canvas backgrounds, smooth scroll reveals, and stat animations.

---

## 📁 Project Structure

```
Averon Portfolio/
├── assets/
│   ├── css/
│   │   └── styles.css      # Core Design Tokens & UI Styles
│   ├── js/
│   │   └── main.js         # Interactive Cursor, Canvas & Scroll Observers
│   └── images/             # Brand Assets & Project Visuals
├── index.html              # HTML5 Semantic Entry Point
├── package.json            # Project Metadata & NPM Scripts
├── .gitignore              # Git Ignore Directives
└── README.md               # Documentation
```

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Installation & Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Local Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

---

## ⚡ Core Features

- **Interactive Canvas Particles**: Mouse-attracting canvas particle engine.
- **Custom Cursor & Follower**: Fluid cursor easing and micro-interactions on hover.
- **Scroll Reveal Animations**: IntersectionObserver triggers reveal transitions and dynamic counter animations.
- **Responsive Layout**: Designed for mobile, tablet, and ultra-wide desktops.
